### Agreed behavior to implement

1. **Shared header and Options.** One shared presentation component with typed workspace adapters; existing controllers retain document, history, picker and job ownership. Keep GZ Editor Pro at top left, a distinct workspace selector, Undo/Redo arrow icons in the same order/style and visible Options text at top right. Use the common deliberate second row for narrow/large-font layouts. The header hides with tool chrome on a free-canvas tap; active guides remain usable and an accessible reveal action exists. Empty workspaces retain the header.
2. **One command owner.** Follow the exact workspace/context table in PRODUCT_SPEC. Consolidate supported New/Open, project Save/Save as/Open, Export and Help in Options, with honest labels and disabled reasons. Remove duplicate header/dock/empty-state major actions. Direct tools, playback, Add layer and child Done/Cancel remain contextual editing actions. Do not fabricate unsupported future commands.
3. **Regular cleanup.** Remove More, Create collage and Histogram from Regular's visible UI, including empty states; do not relocate or rename those entries. Auto tone belongs in Light, Auto WB in Color, Save my look once in Looks. Preserve underlying numerical/diagnostic behavior and compatible legacy data.
4. **Save and dirty identity.** Stable project IDs are independent of names. Save updates the active identity only after successful publication; Save as creates a new identity. Explicit collision handling protects another named project. Dirty compares semantic content to the saved or import/creation baseline; view/chrome changes are not edits. Save of an older revision cannot make newer work clean. Export does not mark native work saved. Named Discard restores saved content; unnamed Discard restores entry content and removes only the discarded unsaved history/recovery branch.
5. **Safe departure.** Ordinary dirty Back, mode switch, New, Open, replacement and Open project use Save / Discard / Cancel even if an in-memory session is retained. Resolve transient menu/dialog/IME/tool state first; one Back commits one navigation result. Save failure, picker cancellation, failed target preparation and canceled predictive Back do not leave or destroy work. Stage destructive disposition until the replacement is usable. An explicitly completed named save remains recorded.
6. **Collage tap and child.** A completed unconsumed free tap selects the hit tile, if any, and toggles chrome once in either visibility state. Margins toggle without changing selection. Tool drag, paint, crop, pinch and canceled streams do not also toggle. Standalone selected-tile photo Open/Save remains explicitly labeled and separate from parent Apply. Direct Done applies once to stable parent/tile identity; direct Cancel restores child entry.
7. **Nested departure.** Dirty child Back offers Apply to tile / Discard tile changes / Cancel (keep editing), and returns only to the parent after Apply/Discard. It does not also exit the parent. A mode/parent departure stages child disposition and then resolves the parent candidate. Later Cancel, failed Save or failed target load preserves original child work and parent transaction state. Saving a standalone photo does not silently Apply it or clean the child relative to entry. Stable IDs, source revisions and conflict handling protect reordered/replaced/deleted tiles and siblings.
8. **Regular → Pro.** Preserve the established Yes = resolved Regular appearance / No = blank Pro semantics. Resume existing Pro is a separate explicit choice, never the meaning of No. Resolve source/target dirty choices transactionally and prepare the target before destructive commit. Explicit source Discard transfers only clearly identified saved/entry appearance; never silently import the discarded snapshot. Cancel/failure preserves both working parents except explicitly completed named saves.
9. **Gesture and asynchronous safety.** Successful continuous gestures commit once; canceled text/shape/privacy drags match Draw/crop rollback. Bind each pending action to workspace/document/source revision, child identity and an execution token. Deduplicate repeated commands; canceled naming/save invalidates its continuation. Late callbacks cannot mutate a different document or revive navigation.
10. **Honest current limits and jobs.** Changed zero-layer Pro setup is protected with Discard setup / Cancel and an explained unavailable Save; do not insert a fake layer or claim a save. Required durable zero-layer documents stay R2. GIF uses a guarded, truthful foreground job with separate preparation/provider stages and request-acknowledgement versus worker-termination status. Copy uncertainty retains recoverable staged output; no false success, destructive retry or universal remote-provider time promise.

These are decided engineering contracts, not claims that the current 0.12.10 APK already behaves this way. Read the full answers for the rationale, edge cases, uncertainty and owner-only gates.
