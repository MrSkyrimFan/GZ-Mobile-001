# GZ Editor Pro 0.8 — one combined Android phone test

**Use only the green, merged-main v0.8 APK**, artifact `gz-editor-pro-debug`. This is a debug app, not the paid final release. Keep your source photos untouched.

1. Launch the app. Confirm **GZ Editor Pro** appears top-left, **Open media** and **Create collage** are available, and © 2026 Greenezone Software LLC remains bottom-left.
2. Choose **Create collage**. Select 2 pictures. Under **Layouts**, try Side by side, Grid, Featured. Both images should appear, uncropped or cropped according to Style → Fit/Fill.
3. Under **Photos**, select Photo 1 → **Edit selected**. Use Exposure or a Look; optionally add text or a black privacy bar. Tap **Done**. Repeat a different edit on Photo 2. Only each respective tile should change.
4. Add more pictures, up to 20 if convenient. Try Mosaic, Filmstrip, Magazine, layout Aspect (4:5 or 9:16), spacing, outside margin, rounded corners, background and Style Fit/Fill. Select a tile directly by tapping it; reorder a few and use Undo/Redo to restore an earlier arrangement. Under Photos, also check that **New collage** asks before clearing, and Undo can restore the old collage.
5. Save the collage as **Test Collage**; use **Saved collages** to open it. Confirm the individual tiles still retain their own editable adjustments. Replace a photo if needed.
6. Export one JPEG or PNG, open in your gallery and examine whether all tiles are present with correct layout and no watermark. A high-res export may take longer on 20 photos. Original source files must be unchanged.
7. Return to normal **Open media** editor. In **Crop → Freeform**, tap the image to hide the bottom UI. The **crop box and corner handles must stay visible and draggable**. Do the same for a blur rectangle, text box and brush guide. Tap again to restore controls.
8. Verify the old Looks, simple photo export, and Privacy opaque bar still function. No need to retest the 56 sliders.

**Send one report:** whether 2-photo and 20-photo layouts worked, tile editing/save/export passed, crop/blur active guides stayed usable, plus any crash, lag, clipping or bad pixels. Attach screenshots only of actual defects.

Note: collages contain local URI references to source photos. If an image provider revokes access, the affected tile may need to be replaced. Do not delete source photos until you are finished.
