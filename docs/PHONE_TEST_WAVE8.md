# GZ Editor Pro 0.9 | One combined physical-phone qualification

Use **only the verified green merged-main debug APK**, not the intermediate branch builds. This replaces the separate 0.8 field test. Video is disabled and is not part of this phone pass.

1. **Modes:** On empty launch check GZ Editor Pro top-left, copyright, Open media and top-right **Photo ▾**. Open menu. Check Regular, Pro, Collage, GIF, and Video marked Coming soon and disabled. Confirm all switches work, no clutter, no lost regular session.
2. **Regular photo:** Open a photo, try Looks, exposure, color, crop/freeform, before/after, Undo/Redo, privacy opaque bar, Save/Export. Ensure controls and crop/blur handles remain visible when toolbar hides. Confirm original untouched.
3. **Photo Pro:** With a regular edited photo open, switch to Pro. Confirm original edited image becomes base layer. Add second image layer. Select each layer, choose **Edit layer**, change separate Looks/text/creative tools and press Done. Edits should never leak between layers.
4. **Pro composite:** Hide/show, reorder up/down, duplicate/delete and Undo/Redo. Move x/y, scale, opacity; try Normal/Multiply/Screen/Overlay and different canvas ratios/backgrounds. Save local project, reopen; export actual PNG and JPG and verify correct pixels and no source overwrite.
5. **Collage from 0.8:** Two-photo Side-by-side and up to 20 photos across Grid/Featured/Mosaic. Independently edit two tiles via full photo editor; arrange/remove/replace, Undo/Redo, saved projects, JPG/PNG export. Hidden-chrome crop, privacy, brush, text selection still interactive.
6. **GIF:** Add 2–6 photos, play/pause, reorder/remove, Undo/Redo. Change timing 100–1500ms, loop vs play once, fit/fill and dimensions; save/reopen project; export .gif and open in GIF-capable viewer. Verify genuinely animated frames, reasonable playback, correct order, no watermark. Optionally try 20 pictures and report lag.
7. **Regressions:** Switch modes repeatedly, return to same regular photo. Check no deleted projects, no internet/account/payment/ad/microtransactions, no button does nothing, no clipping on phone screen, reasonable speed/memory.

Send **one** report with 1–7 pass/fail, actual defect screenshots and any crash/lag or wrong pixels. Only then decide next wave. RAW/16-bit/heal/selections, complex GIF animation, music/video remain explicitly future features.
